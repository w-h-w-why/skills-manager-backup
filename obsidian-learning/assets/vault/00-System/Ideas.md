# 学习想法专区

用户明确要求时立即记录；自然出现有实质内容的新观点、疑问或应用构想时主动记录并简短告知。普通作答、随口感叹不单独建笔记。遵循 Profile 中用户对自动记录的偏好；用户可要求停止、修改或合并。

创建前检索相近想法：同一想法的发展追加到原笔记，有独立问题或方向才新建。用 Idea 模板，短想法保存短笔记，不强行扩写。

每篇分清：

1. **原始想法**：保存实际表达及必要学习上下文；逐字引用与忠实摘要明确区分，不能伪造原话。
2. **整理与润色**：改善结构和表达，保留原意、条件和不确定性。
3. **Agent 延伸**：单独列补充推论、反例、待验证问题或行动建议，标明作者归属。

用带说明的双链连接课程、知识和来源。默认状态 `待探索`，可给出验证方法；只有用户选择后，才转化为练习、实验、项目或课程分支，记录选择和目标。未经选择不能为其自动改课程主线或创建承诺性任务。

发展状态可为 `待探索 → 探索中 → 已验证 / 被反驳 / 暂缓`，以实际证据为准，允许修订。再次学到相关知识时适时带回该想法，不每轮强行打断教学。经验证的结论可以进入共享知识笔记，附验证范围、证据和原想法链接，并保留原始发展历史。
