# 文件链接与导航

实际存在的文档、源码、配置和目录引用使用 Markdown 链接，以当前文档位置计算相对路径。目录层级使用带链接的缩进列表；项目文档目录项链接到实际索引 `README.md`，没有目录索引时直接链接正文。纯文本树可辅助展示，不作为唯一导航。

索引、相关文档、旧 ADR 和问题实现证据均链接真实文件。推荐文件尚未创建时标注待创建，不造死链；模板示例与实际导航分开。

文件或整个主题目录移动、重命名或删除时查找入链并修复，同时重算移动正文对源码、配置和其他主题的相对出链。检查根索引、各级主题索引和执行入口中的旧路径。标题引用优先文件链接；确有必要用锚点时选择稳定标识，并在标题/锚点变化时搜索和验证所有引用。Skill 自身导航只用文件链接，避免依赖生成标题锚点。

路径有空格时用尖括号目标或适当编码。模板中的示例链接生成前按目标文件所在目录适配，裁掉不存在的目标。

简单链接审计只读取涉及的 Markdown，检查目标存在和必要锚点，不加载业务、架构与完整写入规则。只要求检查时输出问题；要求修复时在范围内修复。
